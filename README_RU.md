# BILIMHUB AI — учебная платформа

BILIMHUB объединяет учебный дашборд, траектории навыков, задания, карьерный раздел, AI-наставника, библиотеку курсов и инструменты продуктивности. Интерфейс поддерживает русский, казахский и английский языки, светлую фирменную тему и тёмную тему.

> Важно: демонстрационные вакансии, рейтинги и часть стартовых показателей — примеры интерфейса, а не подтверждённые реальные предложения или данные других пользователей. Прогресс сохраняется локально в браузере.

## Запуск на Windows

1. Установите Node.js LTS: https://nodejs.org/
2. Распакуйте ZIP в отдельную папку.
3. Скопируйте `.env.example` в файл `.env`.
4. Откройте `.env` и добавьте ключ Google AI Studio:
   ```env
   GEMINI_API_KEY=ваш_ключ
   GEMINI_MODEL=
   PORT=3000
   ```
   Не публикуйте `.env` и не отправляйте API-ключ в чат.
5. Откройте терминал **в корневой папке проекта** и выполните:
   ```bash
   npm install
   npm start
   ```
6. Откройте именно **http://localhost:3000**. Не открывайте `public/index.html` двойным щелчком и не запускайте сайт через `file://`: так относительный запрос `/api/mentor` не сможет попасть на сервер и браузер покажет `Failed to fetch`.

## Проверка сервера и AI

- `http://localhost:3000/api/health` — сервер отвечает и показывает, настроен ли ключ (`keyConfigured`).
- `http://localhost:3000/api/models` — список моделей, доступных указанному ключу. Для этого нужен действительный ключ.
- Если чат не отвечает, сначала посмотрите ошибку в терминале, затем проверьте ключ и доступ Google Gemini для вашего аккаунта/региона. Бесплатные лимиты могут меняться.

Сервер подбирает доступную Gemini-модель, которая поддерживает `generateContent`, и повторяет временные ошибки 429/503. Запрос к провайдеру ограничен тайм-аутом 30 секунд. Ключ хранится на сервере в `.env` и не встраивается в браузерный JavaScript.

## Что есть в интерфейсе

- Дашборд прогресса и выбранного учебного пути.
- Учебные направления и задания/челленджи.
- Карьерный раздел с демонстрационными вакансиями.
- AI-чат с историей в браузере, передачей контекста последних сообщений и копированием ответов.
- Библиотека курсов с поиском, категориями, избранным и локальным прогрессом.
- Фокус-таймер, список целей, мини-викторина, заметки, достижения и активность.
- Переключение RU/KZ/EN, светлая/тёмная темы и акцентные цвета.
- 3D-переходы между разделами, наклон карточек, мобильная нижняя навигация.
- Экспорт/импорт локального прогресса в JSON.

## Горячие клавиши

- `Ctrl+K` или `/` — поиск.
- `1–7` — перейти к разделу.
- `T` — переключить тему.

## Важно перед публикацией в интернете

Демонстрационные вакансии, рейтинги и показатели нужно заменить реальными данными перед публичным запуском. Для производственного размещения дополнительно настройте HTTPS, журналирование, лимиты запросов на уровне прокси и политику хранения данных. Не вводите в AI-чат пароли, персональные документы и другую конфиденциальную информацию.


## Новый личный кабинет
Открой «Кабинет» в верхней навигации или нажми кнопку XP справа. Здесь можно редактировать профиль, планировать учебные дни, вести заметки, смотреть достижения и экспортировать данные. Данные профиля сохраняются в localStorage этого браузера.
